# Your folder

Everything you put here is yours – Code Hub never writes anything here by itself.

- Every `.md` file in this folder (subfolders too) shows up as a note in the graph
  and is searchable – for you and for Claude (`hub_search`, `hub_lookup`).
- New note: **+ Note** at the top of the Code Hub view, normally in Obsidian, or
  just drop a file in here.
- `[[Links]]` to other notes, sessions or projects become lines in the graph.
- If a note belongs to a project, put `project: <name>` into its header –
  otherwise it hangs on “General”.
